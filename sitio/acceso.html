Pegá un token de GitHub con permiso de escritura sobre el repositorio del sitio. Queda guardado solo en este navegador; en cada dispositivo (compu, celular) se pega una vez.

cómo sacar el token (una vez)
  1. En GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → p314b.
  3. Permissions → Repository: Contents = Read and write, Actions = Read and write (lo demás, sin acceso).
  4. Vencimiento: el que prefieras. Copiá el token y pegalo acá.

Con ese token, el botón ⚡ publicar del taller guarda la obra en el repo y lanza la publicación (GitHub corre generar_obra.py, recalcular_subgrafo.py, los de la matriz y publicar.py, y Cloudflare actualiza el sitio). En la web aparecen solo las obras con el tilde "Mostrar en el sitio web" y, de ellas, solo los capítulos publicados. Si perdés un dispositivo, revocá el token en GitHub.
